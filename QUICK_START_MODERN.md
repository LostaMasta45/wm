# 🚀 Quick Start Guide - Modern Features

## ⚡ Get Started in 3 Minutes

### 1. **Start the Dev Server**

```bash
npm run dev
```

Visit `http://localhost:3000/dashboard`

---

## 🎯 Core Workflow

### **Basic Flow (3 Steps)**:

1. **📝 Select Template** → Click a brand template from the left sidebar
2. **📤 Upload Poster** → Drag & drop or click to upload your image
3. **💾 Export** → Click "Download PNG" to get your poster

That's it! Your professional poster is ready! 🎉

---

## 🔥 Power User Features

### **Command Palette** (⌘K)

Press `⌘K` (Mac) or `Ctrl+K` (Windows) anywhere:

```
⌘K → Type what you want to do
```

Examples:
- "export" → Quick export
- "grid" → Toggle grid
- "template" → Switch templates
- "history" → View recent exports

---

### **Keyboard Shortcuts**

Press `?` to see all shortcuts. Most useful:

| Shortcut | Action |
|----------|--------|
| `Space` | Quick export current poster |
| `⌘V` | Paste image from clipboard |
| `⌘Z` | Undo |
| `⌘G` | Toggle grid overlay |
| `⌘H` | Toggle UI (focus mode) |
| `1-9` | Switch to template 1-9 |

---

### **Smart Canvas Tools**

When you have a poster loaded:

1. **Zoom**: Scroll wheel to zoom in/out (50% - 300%)
2. **Pan**: Hold `Alt` + Drag to move around
3. **Grid**: Click grid icon for composition guides
4. **Reset**: Click reset icon to return to 100% zoom

---

### **Multi-Format Export**

Export to multiple social media formats at once:

1. Click "Export Formats" tab
2. Select formats you need:
   - ✅ Instagram Feed (1:1)
   - ✅ Instagram Story (9:16)
   - ✅ Facebook Post
   - ✅ A4 Print
3. Click "Export [X] Formats"

All formats will be generated and downloaded!

---

### **AI Caption Generator**

Generate engaging captions with AI:

1. Find "AI Caption Generator" panel
2. Select tone:
   - 😎 **Casual** - Friendly & fun
   - 💼 **Professional** - Business formal
   - 🔥 **Urgent** - Call to action
   - ✨ **Inspiring** - Motivational
3. Click "Generate Caption"
4. Edit if needed
5. Click "Copy Caption + Hashtags"

Paste directly to your social media! 🎉

---

### **QR Code Generator**

Add QR codes to your posters:

1. Open QR Generator panel
2. Enter the URL you want to link
3. Preview QR code
4. Options:
   - Download QR separately
   - Include in exported poster (bottom-right corner)

## 🔧 Troubleshooting

### **Problem: Canvas is blank**
- ✅ Make sure you selected a template first
- ✅ Check if image uploaded successfully
- ✅ Try refreshing the page

### **Problem: Export button disabled**
- ✅ Upload a poster image first
- ✅ Select a template
- ✅ Wait for canvas to finish rendering

### **Problem: Image quality looks bad**
- ✅ Upload higher resolution images (recommended: 1080px+ wide)
- ✅ Avoid screenshots from low-res displays
- ✅ Use AI Enhance feature (coming soon)

### **Problem: Slow performance**
- ✅ Compress large images before upload (keep under 5MB)
- ✅ Close other browser tabs
- ✅ Try using Chrome or Edge (best performance)

### **Problem: Can't find exported posters**
- ✅ Check your Downloads folder
- ✅ Browser may block auto-download (allow in settings)
- ✅ Right-click export button → "Save link as..."
